# Uganda Food Price Prediction

## Project Overview
This project predicts retail food prices across 43 markets in Uganda using machine learning.

## Dataset
WFP Uganda Food Prices — sourced from HDX (Humanitarian Data Exchange)
- 10,164 rows
- 2007 to 2026
- Uganda markets only

## Models Used
- Random Forest Regressor — R2: 94.15%
- Neural Network MLP — R2: 79.16%

## Demo
Built using Gradio — allows users to select a region, market, food item, month and year to get a predicted price in UGX.

## How to Run
1. Open Uganda_Food_Price_Prediction.ipynb in Google Colab
2. Mount your Google Drive and upload wfp_food_prices.csv to REFACTORY folder
3. Run all cells in order
